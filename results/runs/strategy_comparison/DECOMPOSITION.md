# EA-minus-random decomposition (strategy_comparison benchmark)

Real data from `results/runs/strategy_comparison/` -- 5400 evaluation records, encoders=['direct', 'nca', 'rule_based'], strategies=['ea', 'random_search'], 3 seeds/cell, surrogate evaluator, eval_budget=300/cell.

**Purpose and scope**: this benchmark uses `evodevo.evaluation.ppo_runner.evaluate_body_surrogate` -- a fast, deterministic, physics-free proxy (explicitly NOT a scientific result; no PPO training is run) -- so it exists to produce a real, citable decomposition artifact and exercise the six-cell {ea, random_search} x {direct, nca, rule_based} pipeline end-to-end, not to draw locomotion-performance conclusions.

**Investigated and explained (not a bug): why nca/rule_based show 26.0000 +/- 0.0000 under BOTH strategies.** `evaluate_body_surrogate`'s fitness formula is `(h_act_count + v_act_count) + horizontal_symmetry_score`. On a 5x5=25-cell grid this has a hard mathematical CEILING of exactly `25 + 1.0 = 26.0` -- reached by any body where every cell is an actuator (any mix of H_ACT/V_ACT) AND the body is left-right mirror-symmetric (trivially true for an all-one-material grid, and also true for many mixed H/V layouts whose asymmetric cells all sit on the vertical centre column). Confirmed directly: `results/runs/strategy_comparison/nca/Walker-v0/{seed_*,random_search/seed_*}/best_body.npz` are each an all-actuator (or all-actuator-plus-centre-column-variant) grid scoring exactly 26.0 -- e.g. seed 0's ea and random_search bodies are BOTH a uniform 5x5 grid of H_ACT. Both `nca` and `rule_based` reach this ceiling reliably within eval_budget=300 regardless of strategy: rule-based's genome language can fill the entire grid with one `ALWAYS -> SET_ACTUATOR_*` rule in a single developmental step, and NCA's argmax saturates to one dominant material channel for a large fraction of random weight draws (consistent with the P4 depth study's own finding that NCA's channels are frequently near-tied/saturating). `direct`'s genome instead draws each of the 25 cells i.i.d. from a distribution with `empty_prob=0.6` (and the remaining probability split across 4 materials, so ~10% actuator-per-cell) -- an all-25-actuator direct genome has probability on the order of `0.1^25`, astronomically unreachable within 300 evaluations either by random sampling or by resampling-based mutation, which is exactly why `direct` shows normal, non-degenerate seed-to-seed variance (14.13 +/- 1.28) while nca/rule_based do not. This is a genuine, fully mechanistically-explained property of this toy surrogate combined with these two arms' priors, not a budget-gating, caching, or strategy-abstraction bug (verified: seeds 0/1/2 are threaded correctly and distinct into every run's config and RNG; per-evaluation fitness values within each run are non-degenerate and vary normally -- only the final BEST-found value saturates at the shared ceiling). Re-running this same matrix under `--surrogate` false (real PPO, which has no such closed-form ceiling) is required before any interpretable nca/rule_based decomposition number exists; direct's result here is real, non-degenerate signal from the surrogate and needs no such caveat.

**Decomposition framing**: `random_search` (no selection, no mutation, no population -- fresh i.i.d. samples from the encoder's own genome distribution) measures what the encoding's representational PRIOR achieves for free. `ea - random_search` measures what SEARCH (selection + mutation) adds on top. These are different claims: a large `random_search` result with a small `ea - random_search` gap means the encoding's prior is doing the work, not the algorithm.
